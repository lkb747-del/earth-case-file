## ✅ 수업 당일 체크리스트
**수업 전날 / 1시간 전**
- [ ] 학교 노트북으로 **학교망에서** 학생 주소를 열어 위쪽에 초록 「실시간」이 뜨는지 확인 (정곡초·용덕초 기기도 부탁)
- [ ] 교사 화면 ⚙️ → **🧹 데이터 초기화** (리허설 흔적 지우기)
- [ ] 화상회의 화면 공유 창을 **교사 화면 브라우저 창**으로 지정, 브라우저 확대 100%

**수업 흐름 (교사 화면 위쪽 단계 버튼 순서대로)**
1. **도입** → 🎬 오프닝 애니메이션 → 오른쪽 QR 눌러 크게 → 7팀 접속 불(초록) 확인
2. **활동 안내** → ★ 예시 핀 크게 보기로 시범
3. **① 사건 수사** → ▶ 타이머 시작 (20분) → 오른쪽에서 팀별 ①~④ 확인
4. **② 지도 투어** → 정곡초부터 차례로 누르기 (40초 자동) → 「다음 팀 ▶」
5. **🎨 색깔 발견** → 색 버튼 눌러 그 색 핀만 보기 → 「모두 보기」
6. **③ 연결의 실** → 학생 화면 ⑤가 자동으로 열림 → 장난 연결은 ✕ 로 지우기
7. **정리** → 질문 → 단서 1 → 단서 2 → 결론 → O/X 정답 공개

**수업 후**
- [ ] ⚙️ → **💾 결과 내보내기** → **🗑️ 수업 끝 · 방 데이터 지우기**

**문제가 생기면**
- 팀이 핀을 잘못 꽂음 → 그 핀 누르기 → 「↩ 이 팀 핀 다시 꽂게 하기」
- 학생 기기가 꺼졌다 켜짐 → 같은 주소로 다시 열면 하던 단계 그대로 이어짐
- 연결이 계속 안 됨 → 화면에 뜨는 **패들렛 QR** 로 전환

## 지금 바로 시험해 보기 (데모 모드)
1. `로컬에서_열기.bat` 를 더블클릭합니다. 브라우저에 탭 두 개가 열립니다.
   - 교사 화면: `http://localhost:8123/teacher/` (비밀번호: `js/config.js`의 `teacherPassword`, 처음 값 `2026`)
   - 학생 화면: `http://localhost:8123/`
2. 교사 화면 위쪽의 **수업 코드 4자리**를 학생 화면에 누르고 팀을 고릅니다.
3. 교사 화면에서 **① 사건 수사** 버튼을 누르면 학생 화면에 사건 파일이 열립니다.
4. ⚙️ → **🎭 리허설용 가짜 데이터 채우기**를 누르면 7팀 핀 + 연결 5개가 자동으로 채워집니다.

> 데모 모드는 **한 컴퓨터 안의 탭끼리만** 함께 보입니다. 여러 기기에서 쓰려면 Firebase 연결이 필요합니다 → **`FIREBASE_설정안내.md`**
> `.html` 파일을 더블클릭해서 열면 동작하지 않아요. 꼭 `로컬에서_열기.bat` 로 여세요.

## 폴더 구성
| 파일 | 하는 일 |
|---|---|
| `index.html` | 학생 화면 (팀 기기) |
| `teacher/` | 교사 대시보드 (화면 공유용) |
| `view/` | 참관용 읽기 전용 지도 |
| `js/config.js` | **선생님이 고치는 설정** (비밀번호, Firebase 설정, 목표 개수, 투어 시간) |
| `data/` | 수업 콘텐츠 (사실·수치 — 고치지 않음) |
| `database.rules.json` | Firebase 보안 규칙 (5단계에서 적용) |

## 교사 화면 버튼
- 위쪽 단계 버튼: 도입 → 활동 안내 → ① 사건 수사 → ② 지도 투어 → 🎨 색깔 발견 → ③ 연결의 실 → 정리
  - 단계를 누르면 타이머가 그 단계 시간(예: 사건 수사 20분)으로 맞춰집니다. ▶ 로 시작하세요.
  - **③ 연결의 실**로 넘어가면 학생 ⑤단계가 자동으로 열립니다. (옆 패널에서 닫기/열기 가능)
- 핀을 누르면 그 팀의 세 문장이 크게 뜹니다. 잘못 꽂은 팀은 카드 아래 **↩ 다시 꽂게 하기**.
- 연결의 실 목록의 ✕ 로 장난 연결을 지울 수 있습니다.
- ⚙️ 관리: 가짜 데이터, 결과 내보내기(JSON), 초기화, 새 코드, **수업 끝 · 방 데이터 지우기**
